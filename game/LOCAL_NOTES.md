# 鼠鼠大BOSS：本地调试版

## 启动

在 /Users/zhuzhu/Desktop/3DGame 中运行 npm run dev，打开 http://localhost:5173/。
原 validation/ 页面和 assets/ 原始 GLB 均保留。游戏代码在 game/，优化模型副本在 game/public/models/。
本版不需要 API、登录或远程游戏服务，不上传游戏资产。

## 操作

- 点击“开始”进入不限时的交互调试。默认左侧巧克力，右侧粉色锤子。
- PC：A 选择投喂，D 选择敲击，鼠标点击当前抬头的角色使用。
- 手机：人物冒头时，直接点击底部投喂或敲击，自动作用于当前角色，无需再点人物。响应动作期间重复点击不重复计分。
- 右上角暂停按钮：继续、关闭声音、人物图鉴、游戏说明。音乐来源收在游戏说明底部的折叠项。
- 台词只显示气泡，不进行语音朗读。音乐和音效都在本地播放。

## 角色循环

坐着低头（脸仍可见）→抬头→等待操作→角色专属动作和气泡→低头坐回→间隔0.42秒→下一位。
所有时段均严格串行，不会在上一位React/Retreat阶段再生成下一位。

## 专属动作

老板：局部低头、举手护头、星星；DDL：举夹板挡头；摸鱼：举拇指；甩锅：歪头、左右张望；
实习生敲击：帽顶弹起、护住身体，投喂：双手接住、点头；IT：举扳手；HR：双手靠拢比心、眨眼形变；
财务：计算器护在胸前、点头；橘猫：后仰露出肚皮、开心晃动；画饼：大饼举到脸前。
橘猫投喂时，飞行道具自动变为猫零食。实习生两种操作均+5分。

模型原件没有骨骼，以上使用GPU局部形变、整体姿态和辅助道具完成，不是完整骨骼动作捕捉；
指节、眼睑和烘焙在纹理里的表情只能近似表现。IT现有GLB为错误的十人拼图生成结果，仍使用眼镜/耳机/扳手替身。
