# 摸鱼事务所：微信原生3D版 / Office Escape

## 已接入的内容

- 10名原有角色的3D骨骼模型和动作，IT角色的独立扳手、电脑和表情。
- 原有程序化3D工位、日落办公室背景、书架、饮水机、植物、玩具锤和巧克力。
- 30秒挑战、敲击/投喂、正负亲疏计分、连击、称号、最高分、后台暂停、人物图鉴和音乐。
- 首页 `English / 中文` 切换，保存语言偏好。英文包含首页、角色资料、游戏界面、说明、结算和预设角色台词。
- 原生“聊聊”显示3D角色，使用预设回复；网页的自由输入AI私聊尚未移植到原生版。原生版不请求Vercel，不需要配置业务域名。

不是把网页放进 web-view。微信版用原生Canvas/WebGL2、微信文件读取、分包和音频接口；网页版继续使用浏览器和Vercel。

## 先在电脑上运行

在仓库根目录运行（Node.js 22）：

```sh
npm --prefix game ci
npm run build:wechat
npm run test:wechat
```

`build:wechat` 生成 `wechat/dist/`，同时写入本地 `wechat/build-report.json`。当前主包约2.23MiB，总包约25.41MiB；以微信开发者工具实际上传报告为准。构建会检查本项目采用的主包4MiB、总包30MiB预算。

打开微信开发者工具，选择 **小游戏 → 导入**，目录选本文件所在的 **`wechat` 文件夹**，后端服务选“不使用云服务”。配置中的游客AppID仅供本地调试，不是你的正式账号；游客模式不能作为正式上传凭证。代码目录由 `miniprogramRoot: dist/` 指定。

如果修改源代码，重新运行构建，然后在开发者工具点“编译”。不要直接编辑 `dist/game.js`，它会被下一次构建覆盖。

## 你还没注册，接下来这样操作

1. 到[微信公众平台](https://mp.weixin.qq.com/)注册账号，按小游戏入口或游戏类目指引操作，选择你实际拥有的主体。先核对该主体可选的游戏类目和后台要求，再填写名称、简介和图标。不要把它注册成承载普通网页的小程序。
2. 拿到正式 **AppID**，替换 `project.config.json` 中的 `appid`，删除 `isGameTourist` 字段，用对应管理员或开发者微信登录开发者工具。AppID可以提供给开发者；AppSecret、上传私钥和模型Key不要放进仓库。
3. 用正式AppID导入本项目，选择稳定基础库，点“编译”“预览”，分别在iPhone和安卓微信上扫码验收。当前3D渲染依赖WebGL2；不支持时会提示更新微信，不会悄悄降级成2D。
4. 在公众平台按账号后台提示完成主体、游戏类目、备案、游戏资质、隐私等上线材料。具体所需项和可用能力以你的账号后台及微信最新审核要求为准；代码通过本地检查不等于具备上架资格。
5. 真机验收后，在开发者工具点“上传”，填写版本号，例如 `1.0.0`。到后台版本管理中设置体验版、添加体验成员并测试；确认后提交审核。审核通过后，再在后台发布。

本次代码没有接入广告、支付、微信用户资料或在线AI。以后增加这些功能时，需要同步实现对应接口、服务端和隐私说明；直接填写Vercel网址不能替代微信接口适配。在线AI回复的内容处理和上线材料也需要单独准备。

## 真机验收清单

1. 首页封面及五个入口可点击，切换中英文后重新进入仍保留语言。
2. 第一次进入挑战可看到3D分包加载进度；加载成功才开始计时。失败可重试，不能用缺失模型继续游戏。
3. 10名角色、贴图和骨骼动作正常，IT手中工具、锤子、巧克力、家具和背景能显示。
4. 负亲疏敲击得分，正亲疏投喂得分，中立两种均+5；选错扣分，一次冒头不能重复计分；上滑可以投喂。
5. 30秒结束结算，重新开始正常；切到后台后不偷偷消耗时间，回来可手动继续。
6. “聊聊”可选择不同3D角色并投喂/敲击；明确显示这是预设台词。检查中英文长文本、短屏、全面屏安全区和音乐。

## 文件与资产

| 文件 | 用途 |
| --- | --- |
| `src/main.js` | 原生界面、语言开关、触控、存储、音乐和生命周期 |
| `src/stage.js` | Three.js原生3D场景、微信模型读取、贴图加载、骨骼动作和道具飞行 |
| `src/native-platform.js` | 构建时注入的原生接口适配，不向小游戏注入浏览器DOM |
| `src/round.js` | 复用网页版计分和难度的原生对局状态 |
| `../game/src/i18n.js` | 网页和微信共用的中英文文案与角色翻译 |
| `../scripts/build-wechat.mjs` | 构建、资源打包和包体预算检查 |
| `../scripts/wechat-glb.mjs` | 从原GLB无损提取贴图，避免依赖浏览器Blob URL |

主包包含代码、压缩封面、头像和一首有署名的音乐；`models3d` 分包包含16个运行所需3D文件及贴图和背景。原始 `game/public/models/` 不改动，旧版未使用模型和重复模型不占微信包体。`dist/` 和本机开发者工具配置不提交Git，任何电脑都可以从仓库重新构建。

开发参考：[小游戏开发文档](https://developers.weixin.qq.com/minigame/dev/guide/)、[分包加载](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/subpackages.html)、[开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
